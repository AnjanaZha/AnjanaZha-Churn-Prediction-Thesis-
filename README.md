# AnjanaZha-Churn-Prediction-Thesis-
Customer churn is a significant concern for businesses. This research aims to analyze customer transaction data to identify patterns indicative of churn and to develop machine learning models for churn prediction. The methodology is demonstrated using synthetic transaction data generated in Python.
